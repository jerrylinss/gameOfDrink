# 箱子选金额小游戏

实现一个单页小游戏，类型类似《Deal or No Deal（一掷千金）》。

## 一、游戏目标

玩家从 n 个箱子中选择一个作为自己的箱子并挂起，然后依次打开其他箱子。每打开 k 个箱子后，系统根据剩余未打开箱子中的金额计算报价，询问玩家是否接受。

- **接受**：游戏结束，玩家获得报价。
- **不接受**：继续开箱。
- **只剩自己的箱子**：玩家获得该箱子内的金额。

## 二、核心配置

游戏开始前，允许玩家或主持人设置以下内容。

### 箱子数量 n

- 可设置箱子个数，例如 10 个、20 个。
- 箱子按编号显示：1 号、2 号、3 号……n 号。

### 金额列表

- 默认提供一组金额，例如：`0.1`、`1`、`5`、`10`、`20`、`50`、`100`……
- 金额数量应与箱子数量匹配。
- 如果金额数量不等于箱子数量，需要给出提示或自动处理。
- 建议默认自动把金额随机分配到各个箱子中。

### 每个箱子的金额可手动设置

- 玩家可以给每个箱子单独设置金额。
- 也可以不设置，使用默认金额列表自动分配。
- 箱子金额在游戏过程中对玩家隐藏，直到箱子被打开。

### 每轮开箱数量 k

- 可以设置每轮需要打开多少个箱子后才给出报价。
- 例如：
  - 第一轮 `k1 = 3`
  - 第二轮 `k2 = 2`
  - 第三轮 `k3 = 1`
- `k` 可以是固定值，也可以按轮次分别设置。
- 需要支持自定义每一轮的 `k` 值。

### 报价折扣

- 系统报价 = 剩余箱子金额的平均值 × 90%。
- 折扣比例可配置，默认少 10%。

## 三、游戏流程

### 1. 初始化阶段

1. 设置箱子数量 `n`。
2. 设置金额列表，或手动为每个箱子设置金额。
3. 设置每轮开箱数量 `k`。
4. 系统为每个箱子分配编号，并隐藏金额。
5. 将金额随机分配到各箱子中。

### 2. 玩家选择初始箱子

- 屏幕上只显示箱子编号，不显示金额。
- 玩家选择一个箱子作为自己的箱子。
- 该箱子被挂起，暂时不打开，也不参与后续开箱。
- 玩家知道这个箱子里有金额，但不知道具体是多少。

### 3. 开始开箱阶段

- 玩家从剩余未打开的箱子中继续选择箱子翻开。
- 每翻开一个箱子，显示该箱子内的金额。
- 每翻开 `k` 个箱子后，进入一次报价环节。

### 4. 报价环节

计算当前剩余未打开箱子中的金额，包括：

- 玩家一开始选择的箱子
- 尚未被翻开的所有其他箱子

计算这些金额的平均值：

```text
报价 = 平均值 × 90%
```

弹出确认框：“当前报价为 X，是否接受？”

选项：**接受** / **不接受**

**如果接受：**

- 游戏结束。
- 玩家获得报价金额。

**如果不接受：**

- 继续下一轮开箱。
- 按照下一轮的 `k` 值继续。

### 5. 最后一轮

当其他箱子都被打开，只剩下玩家一开始选择的箱子时：

- 不再报价。
- 直接打开玩家自己的箱子。
- 玩家获得该箱子内的金额。
- 游戏结束。

## 四、界面需求

### 主界面

- 显示所有箱子编号。
- 已打开的箱子显示金额。
- 未打开的箱子只显示编号。
- 玩家自己的箱子需要有特殊标记，例如“已选中 / 挂起”。
- 显示当前轮次、剩余箱子数量、已开箱数量等信息。

### 报价弹窗

- 显示当前报价金额。
- 显示“接受”和“不接受”按钮。
- 接受后结束游戏并显示最终获得金额。
- 不接受后关闭弹窗，继续开箱。

### 结束界面

- 显示玩家最终获得的金额。
- 可以显示玩家自己的箱子原本金额，用于对比。
- 提供“重新开始”按钮。

## 五、规则细节

- 箱子编号从 1 开始，到 `n` 结束。
- 每个箱子只能被打开一次。
- 玩家一开始选择的箱子不能被提前打开，直到最后一轮。
- 报价只基于当前尚未打开的箱子金额计算。

报价计算公式：

```text
剩余金额平均值 = 剩余未打开箱子金额总和 ÷ 剩余未打开箱子数量
报价 = 剩余金额平均值 × (1 - 折扣比例)
默认折扣比例 = 10%
```

- 如果剩余未打开箱子数量为 0，则游戏应已结束。
- 如果 `k` 大于剩余可开箱数量，则开完剩余箱子后进入报价或结束。
- 如果玩家不接受报价并继续，直到没有其他箱子可开，则直接获得自己箱子的金额。

## 六、可配置项总结

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 箱子数量 n | 总箱子数 | 10 |
| 金额列表 | 每个箱子可能出现的金额 | 0.1，1，5，10，20，50，100... |
| 手动金额 | 可为每个箱子单独设置金额 | 无 |
| 每轮开箱数 k | 每开 k 个箱子后报价 | 可设置，如 3、2、1 |
| 报价折扣 | 报价比平均值少多少 | 10% |
| 报价方式 | 平均值 × (1 - 折扣) | 平均值 × 90% |

## 七、实现要求

- 可以在页面中设置箱子数量、金额列表、每轮 `k` 值、折扣比例。
- 箱子以网格形式显示，只显示编号。
- 点击箱子可以选择或打开。
- 每轮开够 `k` 个箱子后弹出报价确认框。
- 接受报价则结束，不接受则继续。
- 最后只剩玩家箱子时，自动打开并结算。
- 界面简洁，适合桌面和手机浏览器。
- 代码结构清晰，方便后续修改规则。
- 所有代码放在一个 HTML 文件中，可直接运行。
- 添加必要的注释，方便理解和修改。

## 八、可选增强

如果实现顺利，可以额外加入以下功能：

- 显示历史报价记录。
- 显示已打开箱子的金额列表。
- 支持自定义每轮 `k` 值，例如输入 `3,2,1`。
- 支持重新开始并保留上次配置。
- 增加简单动画效果，例如开箱、报价弹窗。
- 支持保存和读取配置。
