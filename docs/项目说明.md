# 酒桌计时器 · 项目说明

手机端酒桌计时小游戏：正计时可隐藏秒数，倒计时可到 0 才揭晓。技术栈为 Vite + React + Ant Design，可部署到 GitHub Pages。

## docs 怎么用

后续所有需求、说明、变更都写进 `docs/`，开发前先落文档，再改代码。

| 文件 | 用途 |
| --- | --- |
| `docs/项目说明.md` | 项目介绍、目录约定、协作规则 |
| `docs/<功能名>.md` | 单次功能需求，一份需求一个文件 |

建议：

- 新需求用简短中文名，例如 `主题配置.md`、`倒计时隐藏.md`
- 同一功能有后续修改时，优先改原文件，并补「变更」小节，不必另开一份
- 文档写清目标、交互、范围；实现时以文档为准

## 协作规则

1. **先写需求，再开发。** 出需求时先在 `docs/` 新增或更新对应 md，确认范围后再改代码。
2. **一份需求一份 md。** 不要把互不相关的功能堆进同一个文件。
3. **实现对照文档。** 开发完成后，行为应能在对应 md 里找到依据；若实现有取舍，把取舍写回文档。
4. **改需求先改文档。** 交互或范围变化时，先更新 md，再改代码，避免口头需求和代码分叉。
