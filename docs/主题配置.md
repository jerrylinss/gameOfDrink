# 需求：可配置主题

## 背景

当前界面只有暖橘色主题。酒桌场景下需要能换成更亮、更暗或更冷的配色。

## 目标

用户可在设置中切换主题，立即作用于整页，刷新后仍保持上次选择。

## 主题

| 标识 | 名称 | 说明 |
| --- | --- | --- |
| `amber` | 橙色 | 默认。现有暖橙暗色，酒桌感 |
| `day` | 白天 | 浅色背景、深色文字 |
| `night` | 黑夜 | 近黑背景、冷月光强调色 |
| `deep-blue` | 深蓝 | 海军蓝背景、青色强调色 |

## 交互

- 入口：右上角设置面板
- 四个主题四选一，点选后立刻换肤
- 选择写入 `localStorage`（键名 `jiuzhuo-theme`）
- 非法或缺失的存储值回退到橙色

## 范围

覆盖背景、品牌、计时数字、按钮、设置面板、Ant Design 组件和酒杯图标。

不改计时逻辑、隐藏数字规则、音效。

## 验收

- 设置里能看到四个主题并可切换
- 四种主题配色可区分，文字和主按钮可读
- 刷新页面后仍是上次主题
- 正计时 / 倒计时功能与主题无关，表现一致
